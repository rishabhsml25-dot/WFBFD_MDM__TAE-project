ABOUT THIS PROJECT

DRIVE CARE is a digital vehicle maintenance log built for a college PBL demonstration. It uses HTML5 for structure, Tailwind CSS for a responsive interface, and vanilla JavaScript to handle input, calculations and maintenance alerts. All data is stored locally using LocalStorage, and the next service is calculated from the latest actual service mileage plus a 5,000 km interval — not a fixed assumption.
