# 🚗 Road Ready – Vehicle Maintenance Log

Road Ready is a simple web-based **Vehicle Maintenance Log** that helps users manage their vehicle details, mileage, service history, and upcoming maintenance.

## ✨ Features

* 🔐 Simple Login System
* 🚘 Add and update vehicle details
* 📊 Track current mileage
* 🔧 Add service records
* 🗑️ Delete incorrect service records
* 📅 View service history
* ⚠️ Upcoming maintenance alerts
* 🔄 Calculate next service mileage automatically
* 🚪 Logout and clear saved data
* 💾 Uses Browser LocalStorage for data storage
* 📱 Simple and responsive user interface

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* JavaScript
* LocalStorage

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run it using Live Server or open it directly in a browser.

##  How It Works

The user logs into the application and enters vehicle information. The dashboard allows the user to update mileage, add service records, and view upcoming maintenance alerts.

All vehicle and service information is stored in the browser using **LocalStorage**.

## Project Objective

The main objective of this project is to create a simple and user-friendly system for maintaining vehicle service records and tracking upcoming maintenance.
